# Cine-Stream 🎬

Cine-Stream is a React-based movie discovery SPA powered by the TMDB API.

## Features

- Popular movies
- Movie search
- Infinite scrolling
- Debounced search
- Favorites
- LocalStorage persistence
- Lazy-loaded images
- AI Mood Matcher
- Responsive design

## Tech Stack

- React
- Vite
- React Router
- JavaScript
- CSS
- TMDB API
